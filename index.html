Thuộc tính grid-gap trong CSS Grid

Thực hành thiết lập khoảng cách giữa hàng và cột trong bố cục lưới

1. Lý thuyết & Cú pháp

Thuộc tính grid-gap đặt kích thước của khoảng cách giữa các hàng và các cột trong bố cục lưới (CSS Grid).

Nó là một thuộc tính viết tắt (shorthand) cho hai thuộc tính:

  • grid-row-gap: Đặt kích thước khoảng cách giữa các hàng (mặc định: 0).
  • grid-column-gap: Đặt kích thước khoảng cách giữa các cột (mặc định: 0).
Cú pháp viết tắt: grid-gap: <grid-row-gap> <grid-column-gap>;
💡 Lưu ý CSS hiện đại: Trong CSS hiện đại, thuộc tính gap được khuyến khích sử dụng thay cho grid-gap (ví dụ: gap: 30px 10px;). Thuộc tính gap ngắn gọn hơn và hoạt động tốt trên cả CSS Grid lẫn Flexbox.
Ví dụ 1

Thiết lập khoảng cách giữa hàng và cột bằng nhau

Sử dụng grid-gap: 20px; để tạo khoảng cách đều nhau 20px cho cả hàng và cột. (Tương đương với grid-row-gap: 20px; grid-column-gap: 20px;)

CSS: 
.grid-container-1 {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    grid-gap: 20px; /* Hàng và cột đều 20px */
}
.grid-container-1 div {
    background-color: lightblue;
    padding: 20px;
    text-align: center;
}

Thiết lập khoảng cách hàng và cột khác nhau

Sử dụng grid-gap: 30px 10px;: giá trị đầu tiên (30px) cho hàng (grid-row-gap), giá trị thứ hai (10px) cho cột (grid-column-gap).

CSS: 
.grid-container-2 {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-gap: 30px 10px; /* Hàng 30px, Cột 10px */
}
.grid-container-2 div {
    background-color: lightgreen;
    padding: 20px;
    text-align: center;

3. Bảng tổng hợp so sánh

Cách viết Khoảng cách hàng (Row Gap) Khoảng cách cột (Column Gap) Giải thích
grid-gap: 20px; 20px 20px 1 giá trị: áp dụng cho cả hàng và cột
grid-gap: 30px 10px; 30px 10px 2 giá trị: giá trị 1 là hàng, giá trị 2 là cột
gap: 30px 10px; 30px 10px Cú pháp chuẩn hiện đại (hỗ trợ cả Grid và Flexbox)
